BETWEEN OUR TRIPS · SUPABASE

두 사람의 여행을 클라우드에

회원가입·비밀번호는 Supabase Auth, 여행과 공유 정보는 여행 전용 테이블에 보관합니다.

연결 상태를 확인하고 있어요…

1. 기존 Supabase 프로젝트 열기

포폴분석에 사용한 프로젝트로 들어가세요. 프로젝트가 일시 정지되어 있으면 복원하고, Project URL이 현재 서버 설정과 일치하는지 확인해주세요.

Supabase 대시보드 열기 ↗

2. 여행 테이블 준비하기

왼쪽 SQL Editor → New query를 열고 아래 SQL 전체를 붙여 넣은 뒤 Run을 누르세요. 기존 포폴분석 데이터와 Auth 설정은 변경하지 않습니다.

SQL 파일 저장

3. 이메일 로그인 준비하기

Authentication → Sign In / Providers에서 Email 로그인을 사용할 수 있는지 확인하세요. 이메일 인증을 사용하면 가입 메일의 링크를 누른 뒤 로그인합니다.

Authentication → URL Configuration → Redirect URLs에 http://localhost:4310과 http://localhost:4310/**를 추가하세요. 다른 기기에서 접속할 LAN 주소나 공개 배포 주소도 실제 사용할 주소만 추가합니다. 포폴분석의 기존 Site URL은 유지해도 됩니다.

인증 메일이 오지 않으면 스팸함과 Supabase Auth 로그를 확인하세요. 기본 메일 서비스에는 발송 제한이 있으며 실제 운영 시 사용자 지정 SMTP 설정이 필요할 수 있습니다.

4. 여행을 만들고 동행 초대하기

앱에서 회원가입 → 이메일 인증 → 로그인 → 새 여행 → 함께 계획하기 → 초대 코드 생성 순서로 진행하세요. 동행은 별도 계정으로 가입하고 같은 앱에서 초대를 수락합니다.

여행 앱으로 돌아가기 →

데이터가 Supabase에 저장되어도 현재 앱 서버는 PC에서 실행됩니다. 집 밖에서 함께 사용하려면 앱을 HTTPS 주소로 배포해야 합니다.

서버의 비밀 키는 브라우저와 이 안내 화면에 표시되지 않습니다.
