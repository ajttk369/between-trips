# 여행의 사이

국내·해외 여행을 두 사람이 함께 계획하는 한국어 웹앱입니다. Supabase Auth와 데이터베이스로 로그인·비공개 여행·공동 편집을 제공하며 Vercel에 배포할 수 있습니다.

## 실행

Node.js 24.x에서 프로젝트 루트를 기준으로 실행합니다.

```powershell
npm ci
npm start
```

앱은 `http://localhost:4310`, Supabase 준비 안내는 `/setup.html`입니다. 기존 PC에서는 `실행.cmd`도 사용할 수 있습니다. `.env.example`을 참고해 `.env` 또는 Vercel의 환경변수를 설정하세요. `.env`는 Git에 올리지 않습니다.

## 주요 기능

- 여행 생성·수정·삭제, 국내·해외 구분, 예정·지난 여행, JSON 내보내기·가져오기.
- 각자 로그인 후 초대 코드로 2인 공동 사용, 참여 권한 검증과 버전 충돌 처리.
- 저장 장소, 각자의 하트, 댓글, 장소 여러 개를 날짜별 일정에 추가.
- 일정 순서 변경·복사·날짜 이동, 여러 숙소와 체크인·아웃, 예약 자료 첨부.
- Google 지도 또는 Leaflet 지도, 숙소·방문 순서 핀, 직선거리와 실제 경로 거리 구분.
- 준비물·할 일, 입력 환율, 예상·실제 비용과 두 사람 사이 정산.
- 숙소·날짜를 참고하는 AI 추천, 대화로 초안 변경, 검토 후 공동 일정 반영.
- 선택한 기기에 일정·숙소 주소를 저장하는 오프라인 읽기 화면.
- PC·태블릿·휴대폰 레이아웃, 로그인·첫 여행 안내의 4장 여행 사진 슬라이드.

사진은 6.5초마다 전환되며 이전·다음·사진 선택·일시정지와 터치 넘기기를 지원합니다. 키보드 초점·마우스 호버·백그라운드 탭에서는 자동 전환을 멈추며, 모션 줄이기 설정도 존중합니다. 사진 원본은 사용자가 제공한 이미지이며, 배포용 파일은 `public/images/travel`에 보관합니다.

## 프로젝트 구조

| 경로 | 용도 |
| --- | --- |
| `public/` | 앱 화면·단일 공통 스타일·사진·오프라인 화면 |
| `api/`, `server.mjs`, `*-api.mjs` | Vercel API와 서버 |
| `travel-domain.mjs`, `ai-planner.mjs` | 입력 검증·일정 변경·AI 제안 |
| `supabase/` | 여행·AI 데이터베이스 SQL |
| `scripts/` | 배포 빌드·연결 확인 |
| `test/` | 자동 검증과 격리된 화면 검증 서버 |
| `docs/` | 설정·배포·사용 안내 |

`dist/`는 빌드 시 재생성합니다. `data/`는 로컬 SQLite 계정·여행 데이터이므로 임의로 삭제하지 마세요. `node_modules/`는 실행에 필요한 의존성입니다. 두 폴더 모두 Git에 포함하지 않습니다.

## 저장과 외부 서비스 범위

클라우드 모드는 Supabase 연결 실패 시 로컬 저장으로 전환하지 않습니다. Vercel에서는 약 4초 간격으로 여행 버전을 확인합니다. 비밀번호는 Supabase Auth가 관리하고 서버가 사용자와 참여 권한을 검증합니다.

Google·Geoapify·OpenAI 연결은 해당 환경변수 설정이 필요합니다. 실제 영업시간·평점·환율을 임의로 표시하지 않으며, 지도 점선은 직선입니다. Google 장소는 ID를 보관하고 조회 좌표는 페이지 메모리에서 사용합니다.

예약 첨부는 항목당 파일 2개·각 350KB, 여행 전체 합계 1MB입니다. 오프라인 사본에는 예약번호·첨부·메모·AI 대화·지도 좌표를 넣지 않습니다. 로그아웃 시 기기 사본을 삭제하고 재연결 시 참여 권한을 다시 확인합니다.

## 검증

```powershell
npm run check
npm test
npm run build:vercel
```

Windows Edge가 설치된 PC에서는 `npm run check:ui`로 320~1440px의 실제 브라우저 화면과 메뉴·지도 전환·입력창을 별도 검증할 수 있습니다.

`npm test`는 공동 편집·권한·충돌·저장 유지, 실제 PostgreSQL 엔진(PGlite)에서의 SQL, 외부 서비스 모의 응답과 갤러리 동작을 검증합니다. 유료 지도·AI API를 호출하지 않습니다. 실제 Supabase 준비 상태는 `npm run supabase:check`로 별도 확인합니다.
