# 화면과 여행 도구 개선

## 일정 카드와 여행 중 화면

- 일정 카드에는 시간·장소를 먼저 표시합니다. ‘상세 보기’를 펼치면 주소·메모·예상 비용·관련 링크와 순서 변경·복사·수정·삭제 버튼이 나옵니다. 펼친 상태는 같은 여행 화면을 다시 그릴 때 유지합니다.
- 여행 기간에는 여행지 시간대의 오늘 날짜를 기준으로 ‘여행 중 보기’가 자동으로 열립니다. 입력한 시작·종료·체류 시간을 기준으로 현재 일정과 다음 장소, 예약 완료한 오늘 숙소를 보여줍니다. 실제 위치나 방문 여부를 추적하지 않습니다.
- ‘일정 보기’로 언제든 돌아가 편집할 수 있습니다. 다음 장소의 이름 또는 ‘일정 상세’를 누르면 해당 카드가 펼쳐집니다. 여행 전후에는 ‘여행 화면 미리보기’로 첫날 또는 마지막 날을 확인할 수 있습니다.
- 길찾기는 기존 Google Maps 링크를 사용하며 Routes API를 추가 호출하지 않습니다. 새 환경변수나 데이터베이스 설정은 필요하지 않습니다.

## 정산과 준비물, 모바일

- 숙소·예약의 ‘결제 완료’는 실제 지출 반영 여부입니다. 별도의 ‘정산에 포함’을 끄면 실제 지출·날짜별·카테고리별 합계에는 포함하면서 두 사람의 정산액에서만 제외합니다. 지출 기록에도 같은 옵션이 있고, 기존 기록은 기본적으로 정산에 포함됩니다. 연결한 실제 지출이 있다면 그 지출의 정산 옵션을 사용합니다.
- 준비물 체크는 즉시 표시하고 서버 저장을 뒤에서 진행합니다. 연속 클릭은 마지막 상태를 보존하며, 서로 다른 항목은 최신 버전으로 순서대로 저장합니다. 충돌 시 동행의 이름·메모·담당자 변경을 보존하고 체크 필드만 갱신합니다. 실패하면 저장 전 표시로 돌아가고 안내를 보여줍니다. 동행 기기 반영은 기존 동기화 주기를 따릅니다.
- 모바일은 ‘일정 / 장소 / 지도 / 더보기’ 하단 메뉴와 하나의 ‘추가’ 버튼을 사용합니다. 숙소·하루 요약은 접어서 표시하고, 숙소·예약·준비물·예산·AI·여행 관리 기능은 ‘더보기’에 모았습니다. 입력 화면은 전체 화면으로 열고 선택 항목은 ‘추가 정보’에서 펼칩니다.

여행이 있는 계정은 소개 배너 대신 여행 목록부터 표시합니다. 예정된 여행은 출발일순, 지난 여행은 종료일 역순입니다. 첫 여행 안내 배너와 로그인 화면은 사용자가 제공한 여행 사진 4장을 자동으로 전환하며 이전·다음·일시정지·터치 넘기기를 지원합니다. 모바일 로그인 화면은 사진과 글을 위아래로 나누어 표시합니다.

- 일정: 날짜 선택 → 선택한 날짜 요약 → 일정·지도 순서입니다. 변경 기록은 아래에서 펼칠 수 있습니다.
- 지도: ‘오늘 동선 전체’는 그날 일정과 숙소가 들어오도록 맞춥니다. ‘숙소로 이동’은 예약 완료 숙소 주변을 확대합니다. 점선은 실제 이동 경로가 아닙니다.
- 장소 일괄 추가: ‘함께 저장한 장소’에서 체크 → ‘선택한 장소 일정에 추가’ → 날짜를 선택합니다. 최대 100개까지 한 번에 추가하며, 같은 날짜에 이미 있는 장소나 동행이 삭제한 장소가 있으면 전체 저장을 거절합니다.
- 일정 복사·이동: 일정 카드의 달력 버튼에서 대상 날짜와 작업을 고릅니다. 메모·체류 시간·링크·비용을 보존하며 시간은 기본적으로 비웁니다. 복사한 일정의 비용도 예산에 반영됩니다.
- 예약 자료: 숙소·예약 등록/수정에서 PNG·JPG·WebP·PDF를 항목당 2개, 각각 350KB까지 첨부합니다. 여행 전체 첨부 합계는 1MB입니다. 원본 크기를 자동으로 줄이지 않으므로 큰 파일은 용량을 줄여 첨부하세요.
- 첨부는 기존 서버 권한 검사를 거쳐 여행 JSON 문서 안에 보관합니다. 공개 파일 URL이나 별도 Storage 버킷을 만들지 않습니다. 파일 다운로드와 JSON 내보내기를 한 뒤의 사본은 내려받은 기기에서 관리합니다. 첨부가 클수록 공동 편집 시 데이터 전송량도 늘어납니다.
- 오프라인: 여행 상단 ‘오프라인 저장’ → ‘기기에 저장’으로 현재 기기에 일정과 숙소 주소를 보관합니다. 이후 연결 중에는 갱신됩니다. 저장한 일정은 `/offline.html`에서 읽을 수 있고 인터넷이 끊긴 뒤 앱에 접속해도 이 화면이 열립니다.
- 오프라인에는 예약번호·첨부·메모·계정 이메일·대화·지도 좌표를 저장하지 않습니다. 지도와 편집은 인터넷이 필요합니다. 참여 권한 변경은 재연결 시 확인하며, 로그아웃하면 모든 오프라인 사본을 삭제합니다. 저장 해제 버튼이나 오프라인 화면에서도 기기 사본을 삭제할 수 있습니다.

추가 SQL, 환경변수, 유료 서비스 설정은 필요하지 않습니다. 기존 Vercel 배포에 파일을 함께 업로드하면 됩니다. 서비스 워커는 HTTPS 또는 localhost에서 작동하며, 브라우저의 저장 차단/비공개 모드에서는 오프라인 저장이 실패할 수 있습니다. 실패한 경우 저장 완료로 표시하지 않습니다.

검증: 문법 검사, Vercel 빌드, 기존 공동 편집·Supabase 테스트와 신규 여행 도구 테스트를 실행합니다. 실제 유료 지도/AI 호출과 실제 사용자의 여행 데이터 변경은 하지 않습니다. 실제 Edge 브라우저에서 320·375·760·768·1000·1024·1440px, 여섯 메뉴·모바일 메뉴·입력창·지도 전환을 검증했습니다. Windows Edge가 설치된 PC에서는 npm run check:ui로 격리된 검증을 다시 실행할 수 있습니다.
